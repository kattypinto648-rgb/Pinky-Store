# Pinky Store — PHP + TypeScript + MySQL

Tienda online de indumentaria femenina. Proyecto Informático II.

## Requisitos previos

- **Docker Desktop** para Mac: https://www.docker.com/products/docker-desktop/
- **VS Code** con estas extensiones:
  - Dev Containers (Se recomienda)
  - PHP Intelephense
  - Docker
  - MySQL (opcional)
